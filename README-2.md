# Vibe Social App

Vibe is a beginner-friendly front-end prototype for a social networking app. It is designed to demonstrate a modern feed, post creation, discovery areas and a responsive layout.

## Features in this prototype

- Responsive desktop and mobile layout
- Sample social feed
- Create text posts
- Save posts in the current browser using localStorage
- Like buttons
- Basic post search
- Vibe World discovery preview
- Mobile navigation

## Run it

1. Download or clone this repository.
2. Keep the folders and files in the same structure shown below.
3. Open `index.html` in a web browser.

No build tools are required for this prototype.

## Publish with GitHub Pages

1. Create a GitHub repository named `vibe-social-app`.
2. Upload the project files and folders. Make sure `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under the build and deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. After GitHub finishes publishing, it will show your site address in the Pages section.

## Important limitations

This is a front-end learning prototype, not a production social network. Posts are stored only in the browser that created them. There is no account system, shared database, private messaging service, moderation system or real-time multi-user feed yet.
